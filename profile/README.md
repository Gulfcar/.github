# Gulf Car

شركة **عربة الخليج (Gulf Car)** تطور وتدير منصات رقمية داخلية لدعم التشغيل، إدارة الخدمات، والعمليات الميدانية.

## GitHub engineering standards

نستخدم GitHub لإدارة دورة التطوير كاملة: التخطيط، Issues، الفروع، Pull Requests، الفحوصات الآلية، التوثيق، والأمان.

المبادئ الأساسية:

- لا تُحفظ كلمات المرور، مفاتيح API، الرموز السرية، ملفات `.env` أو بيانات العملاء في Git.
- التطوير يتم في فروع قصيرة، والتغييرات المهمة تمر عبر Pull Request ومراجعة وفحوصات آلية متى كانت متاحة.
- كل مستودع يحتوي على توثيق واضح للتشغيل والاختبار والنشر والاسترجاع عند الفشل.
- تغييرات قواعد البيانات، المصادقة، الصلاحيات، الرسائل، البيانات الحساسة، والنشر تعامل كتغييرات عالية المخاطر.
- Issues هي المرجع للـbugs والميزات والـtechnical debt؛ ولا تُنشر تفاصيل الثغرات أو الأسرار في Issues عامة.
- مستودعات الأنظمة الداخلية تبقى Private ما لم توجد حاجة واضحة لاعتماد غير ذلك.

## Repository privacy

لا نعرض قائمة المستودعات الداخلية أو نسب جاهزيتها في الصفحة العامة. تفاصيل المشاريع وحالتها التشغيلية تُدار داخل المستودعات الخاصة وأدوات التخطيط المخصصة لها.

---

Organization-wide contribution, security, support, Pull Request, and Issue defaults are maintained in this `.github` repository. Repository-specific rules override these defaults where present.
