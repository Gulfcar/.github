# Gulf Car GitHub Standards

This special `.github` repository contains organization-wide defaults for Gulf Car repositories.

Repository-specific policies and templates take precedence when a repository contains its own versions.

## Organization defaults

- `CONTRIBUTING.md` — baseline development and review workflow.
- `SECURITY.md` — vulnerability and secret-handling policy.
- `SUPPORT.md` — where normal product/support requests belong.
- `.github/PULL_REQUEST_TEMPLATE.md` — default Pull Request checklist.
- `.github/ISSUE_TEMPLATE/` — default Bug, Feature, and Technical Debt forms.

## Principle

Default files here should stay generic. Application-specific branching, deployment, database, testing, and security requirements belong in each application's repository.
